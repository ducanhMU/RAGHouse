## Deployment Steps

### Step 1: Initial Setup

```bash
# Clone repository (if applicable)
git clone <your-repo>
cd rag-v2-ultimate

# Verify all files present
ls -la init-db.sql docker-compose.yml

# Create .env file
cp .env.example .env
```

- [ ] Repository cloned
- [ ] `init-db.sql` verified in root directory
- [ ] `.env` file created

### Step 2: Configure Environment

Edit `.env` file:

```bash
nano .env
```

**Required Configuration:**

1. **Google Gemini API Key** (highly recommended):
   ```bash
   GOOGLE_API_KEY=your_actual_key_here
   ```
   Get free key at: https://aistudio.google.com/app/apikey

2. **PostgreSQL Password** (auto-generated by setup.sh):
   ```bash
   POSTGRES_PASSWORD=<secure-random-password>
   ```

3. **GPU Batch Size** (adjust based on your GPU):
   ```bash
   EMBEDDING_BATCH_SIZE=64  # For 16GB+ VRAM
   EMBEDDING_BATCH_SIZE=32  # For 12GB VRAM
   EMBEDDING_BATCH_SIZE=16  # For 8GB VRAM
   EMBEDDING_BATCH_SIZE=8   # For CPU-only
   ```

- [ ] `.env` configured
- [ ] `GOOGLE_API_KEY` set (or acknowledged CPU-only mode)
- [ ] `EMBEDDING_BATCH_SIZE` adjusted for hardware

### Step 3: Launch System

**Option A: Automated Setup (Recommended)**

```bash
chmod +x setup.sh
./setup.sh
```

**Option B: Manual Setup**

```bash
# Build containers
docker-compose build

# Start services
docker-compose up -d

# Wait for initialization (~2 minutes)
watch -n 2 'docker-compose ps'
```

**Option C: Using Makefile**

```bash
make setup   # First time
# OR
make start   # If already configured
```

- [ ] Containers built successfully
- [ ] All services started
- [ ] No errors in logs

## Backup Strategy

### Initial Backup

```bash
# Create backup directory
mkdir -p backups

# Backup all volumes
make backup

# OR manually:
docker run --rm \
  -v rag-v2-ultimate_postgres_data:/data \
  -v $(pwd)/backups:/backup \
  ubuntu tar czf /backup/postgres_$(date +%Y%m%d).tar.gz /data
```

- [ ] Backup directory created
- [ ] Initial backup successful
- [ ] Backup file verified (non-zero size)

### Backup Schedule

Set up automated backups:

```bash
# Add to crontab
crontab -e

# Daily backup at 2 AM
0 2 * * * cd /path/to/rag-v2-ultimate && make backup

# Weekly cleanup (keep 30 days)
0 3 * * 0 find /path/to/rag-v2-ultimate/backups -name "*.tar.gz" -mtime +30 -delete
```

- [ ] Backup cron job configured
- [ ] Cleanup cron job configured
- [ ] Backup location has sufficient space

## Security Hardening (Production)

### Firewall Configuration

```bash
# Allow only necessary ports
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 8501/tcp  # Streamlit (or use reverse proxy)
sudo ufw deny 8000/tcp   # API (expose only via reverse proxy)
sudo ufw deny 5433/tcp   # PostgreSQL (internal only)
sudo ufw deny 19530/tcp  # Milvus (internal only)
sudo ufw enable
```

- [ ] Firewall rules configured
- [ ] Only UI port exposed publicly
- [ ] Database ports blocked from external access

### Password Rotation

```bash
# Change PostgreSQL password
# 1. Update .env
nano .env
# Set new POSTGRES_PASSWORD

# 2. Update database
docker exec -it rag_postgres psql -U rag_user -d rag_db -c \
  "ALTER USER rag_user WITH PASSWORD 'new_password';"

# 3. Restart services
docker-compose restart
```

- [ ] Strong passwords set
- [ ] Passwords documented securely
- [ ] Password rotation schedule planned

## Troubleshooting Reference

### Common Issues

| Symptom | Diagnosis | Fix |
|---------|-----------|-----|
| `init-db.sql not found` | File not in root | Move to project root |
| Services keep restarting | Missing .env | Create from .env.example |
| GPU not detected | Toolkit missing | Install nvidia-container-toolkit |
| Slow embedding | CPU mode | Add GOOGLE_API_KEY or increase batch size |
| Database connection timeout | PostgreSQL starting | Wait 30s and retry |
| Milvus connection failed | Dependencies not ready | Restart etcd, minio, milvus |

### Quick Recovery Commands

```bash
# Soft restart
docker-compose restart

# Hard restart (preserves data)
docker-compose down
docker-compose up -d

# Nuclear option (⚠️ DELETES DATA)
docker-compose down -v
./setup.sh
```
